# Launch kit

## Short post

I built AI Usage Widgets: free, open-source macOS menu-bar trackers for
ChatGPT/Codex and Claude Code usage. It shows usage percentages, reset times,
and local pacing guidance so you can use your allowance without accidentally
hitting the limit early.

Install one tracker or both: https://github.com/arjun-rishi-2004/ai-usage-widgets

## Longer post

AI Usage Widgets is a native macOS project for people who use ChatGPT/Codex
and Claude Code regularly. It places your current usage and reset timing in
the menu bar, supports each provider separately, and gives a local pacing
recommendation when both trackers are running.

It is source-only, has no telemetry, and does not read prompts or
conversations. ChatGPT/Codex support uses the installed ChatGPT app. Claude
support is clearly marked experimental because its usage endpoint is not a
documented public API.

Project: https://github.com/arjun-rishi-2004/ai-usage-widgets
Website: https://arjun-rishi-2004.github.io/ai-usage-widgets/
