ChatGPT and Codex usage tracker for Mac

AI Usage Widgets is an open-source macOS utility that reads available Codex rate-limit information from the installed ChatGPT app and displays your current usage percentage in the menu bar.

What it shows

  • Current usage percentage
  • Session and weekly reset information when available
  • Local pacing guidance designed to keep a reserve

Install

Build and install the ChatGPT tracker with Scripts/install.sh chatgpt.
