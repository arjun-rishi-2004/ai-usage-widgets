# Contributing

Thank you for improving AI Usage Widgets.

Before opening a pull request, run the local checks described in the README.
Keep contributions source-only: do not add compiled apps, local snapshots,
launch agents, logs, credentials, tokens, or personal information.

The project has no telemetry. Do not add analytics or background networking.
Network calls must remain limited to the provider usage requests documented in
the repository. Changes involving credentials or locally persisted data must be
called out in the pull request description.
